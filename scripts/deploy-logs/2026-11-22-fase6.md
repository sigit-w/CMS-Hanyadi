## Addendum — Fase 6c: Perbaikan Akses Peserta Tryout

- Gejala: halaman peserta menampilkan "Sesi berakhir. Silakan masuk kembali." setelah login.
- Diagnosis: akun `peserta` hanya memiliki permission `tryout.access` dan `presentation.read`; UI memanggil `/api/v1/questions?ready_version=v1` yang dijaga `questions.read`, sehingga 403 diterjemahkan sebagai sesi habis. Terbukti dengan akun peserta uji: `/questions` → 403, `/presentation/questions/1` → 200.
- Perbaikan backend: endpoint baru `GET /api/v1/tryout/questions` dijaga `tryout.access`, mengembalikan hanya soal dengan readiness `is_ready=true` untuk versi diminta, tanpa kunci jawaban/pembahasan/field CMS lain. OpenAPI diperbarui.
- Perbaikan frontend tryout: `loadQuestions()` memakai endpoint baru; `SessionError` menyimpan status HTTP, 403 ditampilkan sebagai "Akun Anda tidak memiliki akses tryout."; aset statis dibump ke `?v=4`.
- QA: 68/68 test lulus (T-02, T-03, T-05, T-07 diperbarui; T-08 menegaskan peserta tetap 403 di endpoint CMS).
- Verifikasi produksi dengan akun peserta sementara: `/auth/me` 200 (permission `tryout.access`, `presentation.read`), `/tryout/questions` 200, `/questions` 403, `/presentation/questions/1` 200, `app.js?v=4` terlayani. Akun uji dibersihkan.
- `bank-soal-api.service` direstart; service active, memory available 482 MB, tidak ada OOM.
- Release gate Fase 6c: **GO**.
